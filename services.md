# Services

## AI agent infrastructure
Multi-agent orchestration, LLM gateway and routing, retrieval systems,
voice interfaces. We build agents that run reliably in production, not demos.

## Mobile and application development
Native Android (Kotlin/Compose) and cross-platform React Native. Launchers,
device automation, offline-capable clients.

## Fintech and ledger systems
Payment flows, token and ledger design, reconciliation, compliance-aware
architecture.

## Automation and integration
Internal tooling, workflow automation, API and third-party integration.

## How we work
1. **Scope** — a short paid discovery to define the problem and constraints
2. **Build** — iterative delivery with working software at each milestone
3. **Handover** — documentation, deployment, and knowledge transfer
